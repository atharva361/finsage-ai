# FinSage AI 🧠

> **A cautious AI-powered personal financial planner** that gathers your financial data, predicts cash flow, tests different payment strategies, and recommends the safest personalized option.

## 🚀 Live Demo

Open `index.html` directly in any browser — no server needed.

## ✨ Features

| Feature | Description |
|---|---|
| 📊 **Cash Flow Prediction** | 12-month income & expense projection with inflation + income growth |
| 🔬 **Scenario Simulation** | Tests Lump Sum, EMI, and Defer & Save strategies simultaneously |
| 🛡️ **Risk Scoring** | 0–100 safety score per scenario (emergency fund · savings rate · debt ratio) |
| 🤖 **AI Advisor** | Personalized plain-English reasoning for the safest recommendation |
| 🏆 **Health Score** | Composite financial health ring with mini-bar breakdowns |
| 💡 **Insights** | Automated observations about your financial strengths & risks |

## 🧭 How it Works

1. **5-Step Wizard** — Enter income, expenses, savings, debts, and goals
2. **Dashboard** — View charts, health score, and 12-month projections
3. **Purchase Planner** — Enter any item → Agent simulates all 3 payment paths
4. **Recommendation** — AI picks the safest option with personalized reasoning

## 🛠️ Tech Stack

- **HTML5** — Semantic structure
- **Vanilla CSS** — Dark glassmorphism design system
- **Vanilla JS** — Agent logic (no frameworks)
- **Chart.js** — Interactive charts (CDN)

## 📁 Files

```
index.html   — App shell + all views
style.css    — Design system (dark glassmorphism)
app.js       — Agent engine (cash flow · scenarios · risk · advisor)
```

## 🔒 Privacy

All data stays 100% local in your browser. Nothing is sent to any server.
